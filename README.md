# Third-Party & Vendor Risk Management – Assessing the Supply Chain

## Overview

This repository contains my Week 5 internship assignment completed during the Sohail Smart Solutions Summer Training Program 2026.

The purpose of this assessment is to evaluate third-party and supply chain cybersecurity risks for a fictional client, EduTrack Learning Solutions. The report follows the principles of Governance, Risk, and Compliance (GRC) and aligns with ISO/IEC 27001:2022 supplier relationship controls.

The assessment covers:

- Third-party risk management
- Supply chain security
- Vendor risk lifecycle
- ISO/IEC 27001 Annex A.5.19–A.5.22
- Vendor Risk Assessment
- Vendor Security Questionnaire

## Repository Contents

| File | Description |
|------|-------------|
| vendor-risk-assessment.md | Complete Vendor Risk Assessment report |
| vendor-risk-assessment.csv | Vendor Risk Assessment table |
| questionnaire.md | Vendor Security Questionnaire |

## Key Learning Outcomes

Through this activity I learned how organizations assess supplier cybersecurity risks before onboarding vendors, continuously monitor supplier security throughout the relationship, and apply ISO/IEC 27001 controls to strengthen overall security posture.

This assignment builds directly on previous work completed during Weeks 3 and 4, extending the organization's GRC program to include third-party and supply chain risk management.
